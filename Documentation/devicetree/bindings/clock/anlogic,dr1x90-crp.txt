* Anlogic CRP

The Anlogic CRP generates and supplies clock to various controllers within the SoC.
The clock binding described here is applicable to dr1x90 SoC's.

Required Properties:

- compatible: should be one of the following,
	"anlogic,dr1x90-crp"
- reg: physical base address of the controller and length of memory mapped
  region.
- clocks: Reference to the parent clocks
- #clock-cells: should be 1.
- #reset-cells: should be 1.

Each clock is assigned an identifier, and client nodes can use this identifier
to specify the clock which they consume.

All available clocks are defined as preprocessor macros in corresponding
dt-bindings/clock/anl_dr1x90_crp.h header and can be used in device tree sources.

External clocks:

The cryst_osc clock used as input for the plls is generated outside the SoC. It is
expected that it is defined using standard clock bindings as "cryst_osc".

Example: Clock Management Unit node:

	crp: crp@f8801000 {
		compatible = "anlogic,dr1x90-crp";
		reg = <0x0 0xf8801000 0 0x0400>;
		clocks = <&cryst_osc>;
		clock-names = "cryst_osc";
		#clock-cells = <1>;
		#reset-cells = <1>;
		status = "okay";
	};

Example: serial controller node that consumes clock generated by the clock
management unit:

	&serial0 {
		clocks = <&crp CLK_UART>, <&crp CLK_APB>;
		clock-names = "baudclk", "apb_pclk";
	};
