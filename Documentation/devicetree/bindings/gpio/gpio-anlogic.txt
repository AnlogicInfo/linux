Anlogic AXI GPIO controller

Dual channel GPIO controller with configurable number of pins
(from 1 to 32 per channel). Every pin can be configured as
input/output/tristate. Both channels share the same global IRQ but
local interrupts can be enabled on channel basis.

Required properties:
- compatible : Should be "anlogic,axi-gpio-1.00.a"
- reg : Address and length of the register set for the device
- #gpio-cells : Should be two. The first cell is the pin number and the
  second cell is used to specify optional parameters (currently unused).
- gpio-controller : Marks the device node as a GPIO controller.

Optional properties:
- interrupts : Interrupt mapping for GPIO IRQ.
- anlogic,all-inputs : if n-th bit is setup, GPIO-n is input
- anlogic,dout-default : if n-th bit is 1, GPIO-n default value is 1
- anlogic,gpio-width : gpio width
- anlogic,tri-default : if n-th bit is 1, GPIO-n is in tristate mode
- anlogic,is-dual : if 1, controller also uses the second channel
- anlogic,all-inputs-2 : as above but for the second channel
- anlogic,dout-default-2 : as above but the second channel
- anlogic,gpio2-width : as above but for the second channel
- anlogic,tri-default-2 : as above but for the second channel


Example:
gpio: gpio@80000000 {
	#gpio-cells = <2>;
	compatible = "anlogic,axi-gpio-1.00.a";
	gpio-controller ;
	interrupts = <GIC_SPI 82 IRQ_TYPE_LEVEL_HIGH>;
	reg = <0x0 0x80000000 0x0 0x10000>;
	anlogic,all-inputs = <0x0>;
	anlogic,all-inputs-2 = <0x0>;
	anlogic,dout-default = <0x0>;
	anlogic,dout-default-2 = <0x0>;
	anlogic,gpio-width = <0x2>;
	anlogic,gpio2-width = <0x2>;
	anlogic,interrupt-present = <0x1>;
	anlogic,is-dual = <0x1>;
	anlogic,tri-default = <0xffffffff>;
	anlogic,tri-default-2 = <0xffffffff>;
} ;
